# گزارش آزمایش میثاق ۲

تاریخ اجرا: ۲۰۲۶-۱۱-۰۱

## نتایج واقعی

- سرور استاتیک روی پورت ۳۰۰۰ اجرا شد و `/`، `/admin/` و `/manus-routes.json` با HTTP 200 پاسخ دادند.
- صفحه عمومی در Playwright باز شد؛ ساختار RTL، عنوان فارسی، فرم و مسیر ورود مدیران قابل مشاهده بود.
- validation خالی فرم اجرا شد و خطاهای عنوان، موضوع، زمان، محل و شرح واقعه نمایش داده شدند؛ هیچ RPC در این مرحله فراخوانی نشد.
- ورود واقعی مدیر با Supabase Auth موفق شد. درخواست token با HTTP 200 و درخواست خواندن `mithaq_reports` نیز با HTTP 200 برگشت.
- یک گزارش مشخصاً علامت‌گذاری‌شده با عنوان `[TEST] Mithaq Playwright validation` از مسیر عمومی ثبت شد، کد پیگیری واقعی `M2-2779306923` دریافت شد و سپس همان رکورد پاک‌سازی شد.
- بررسی anonymous به `mithaq_reports` با HTTP 401 برگشت؛ این نتیجه نشان می‌دهد RLS از خواندن عمومی جلوگیری می‌کند.
- یک خطای اولیه RPC به دلیل resolve نشدن `extensions.gen_random_bytes` پیدا و اصلاح شد؛ تلاش بعدی RPC با HTTP 200 موفق شد.
- هشدار cookie مربوط به Cloudflare در اتصال WebSocket Realtime فقط در کانکتور آزمایشی مشاهده شد و از کد برنامه نیست. در محیط انتشار باید اتصال Realtime با مرورگر واقعی و دامنه نهایی دوباره بررسی شود.

## موارد باقی‌مانده برای انتشار نهایی

تست میکروفون وابسته به permission دستگاه است و باید روی مرورگر نهایی با ورودی واقعی یا mock کنترل‌شده اجرا شود. تست upload فایل و signed URL، آزمون Realtime بین دو نشست مدیر و Lighthouse روی URL نهایی GitHub Pages پس از انتشار اجرا می‌شوند. هیچ‌کدام پیش از اجرای واقعی موفق اعلام نمی‌شوند.

## انتشار نهایی

- repository به `misaghsafari1389-cell/mithaq-2` منتقل و Public شد.
- GitHub Pages از `main / (root)` فعال شد.
- URL عمومی، URL پنل مدیریت و `manus-routes.json` در ۲۰۲۶-۱۱-۰۱ با HTTP 200 بررسی شدند.
