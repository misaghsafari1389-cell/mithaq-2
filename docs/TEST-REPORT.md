# گزارش آزمایش میثاق ۲

تاریخ اجرا: ۲۰۲۶-۱۱-۰۱

## نتایج واقعی اصلاح جدید

- صفحه عمومی فقط عنوان گزارش، سطح فوریت و ضبط صوتی را نمایش می‌دهد؛ فیلدهای شرح واقعه، تاریخ، ساعت، محل، افراد، موضوع‌بندی و تصویر حذف شده‌اند.
- گزینه «عادی» به‌صورت پیش‌فرض انتخاب است و گزینه‌های «ضروری» و «فوری» نیز فعال‌اند.
- ضبط واقعی `MediaRecorder` با موج صوتی، مدت‌زمان، پخش، حذف و ضبط مجدد آزمایش شد؛ یک تست synthetic microphone، مدت `۰۰:۰۱` و audio preview معتبر تولید کرد.
- ارسال بدون فایل صوتی متوقف شد و پیام «ضبط صدا برای ارسال الزامی است.» نمایش داده شد.
- یک گزارش صوتی واقعی از مسیر عمومی با فوریت «فوری» ثبت شد؛ RPC سرور با `now()` زمان را تولید کرد، فایل در Storage ذخیره شد، attachment ثبت شد و کد پیگیری واقعی `M2-1389F13C3E` دریافت شد.
- همان گزارش در پنل `/admin/` بدون صفحه ورود، با HTTP 200 و بدون login screen دیده شد؛ عنوان، فوریت، تاریخ و ساعت شمسی، وضعیت و شمارنده گزارش‌ها نمایش داده شد.
- گزارش‌های آزمایشی و فایل orphan آزمایش ناموفق پس از بررسی حذف شدند؛ اطلاعات قبلی سامانه حذف نشده است.
- anonymous read اکنون عمداً HTTP 200 دارد، چون انتخاب صریح کاربر پنل مدیریت بدون لاگین بوده است. این یعنی هر فردی که URL پنل را بداند می‌تواند داده‌های گزارش و عملیات مدیریتی را مشاهده یا تغییر دهد.
- خطای cookie `__cf_bm` فقط در اتصال WebSocket Realtime کانکتور آزمایشی دیده شد و از کد برنامه نیست؛ درخواست REST فهرست گزارش‌ها HTTP 200 بود.

## محدودیت امنیتی پذیرفته‌شده

به‌دلیل انتخاب «بدون لاگین»، RLS و RPCهای مدیر برای anon باز شده‌اند و bucket صوتی نیز برای خواندن پنل عمومی شده است. این پیاده‌سازی فقط در صورتی مناسب است که عمومی بودن گزارش‌ها و کنترل پنل عمداً پذیرفته شده باشد.
